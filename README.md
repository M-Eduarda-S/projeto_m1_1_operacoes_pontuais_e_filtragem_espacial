# Projeto M1.1 – Operações Pontuais e Filtragem Espacial

## Descrição
Este repositório contém a implementação do **Projeto M1.1 – Operações Pontuais e Filtragem Espacial**.

O trabalho foi desenvolvido em `Python` utilizando o `Google Colab` e aborda operações de processamento digital de imagens, como manipulação de pixels, manipulação de bits, transformações de histograma, detecção de bordas e filtros de imagens.
